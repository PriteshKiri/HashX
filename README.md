# Introduction

This is a react-based chrome extension boilerplate. You'll be able to see a sidebar when you install this extension locally on your system. Have used Tailwind for styling this extension.

Follow these step to get started:

### `npm i`

Installs all the dependencies 

### `npm run build`

Builds the app and exports the content script in the extension folder of the repository.

## How to install the extension?

#### Step - 1

Visit the Chrome extension developer dashboard by clicking [here](chrome://extensions/)
The dashboard looks like this.

![](https://res.cloudinary.com/ddlhk5yje/image/upload/v1685130155/Screenshot_2023-05-27_at_1.12.30_AM_v2bfp7.png)

</br>

#### Step - 2

Turn on the developer mode at the top right corner of the dashboard.

Click on the **Load unpacked** button on the top left and upload the **extension folder** from the cloned file here.

Once done, the extension card will be shown in the dashboard.

![](https://res.cloudinary.com/ddlhk5yje/image/upload/v1685130044/Screenshot_2023-05-27_at_1.05.07_AM_uuy1ii.png)

</br>

#### Step - 3

Pin the extension and visit any website and refresh. It will open a small side nav bar on the browser.
